プライバシーポリシー

制定日: 2026年9月28日

1. 対象

本ポリシーは、個人用ツール「youtube-news-shorts」（以下「本アプリ」）に適用されます。本アプリは運営者本人が所有するYouTubeチャンネルへの動画アップロードにのみ使用します。

2. 取得する情報

本アプリは Google OAuth を通じて YouTube Data API へのアクセス権限を取得し、動画のアップロードおよび再生リストへの追加を行います。

3. 情報の利用と保存

取得した認証情報は、運営者本人のチャンネルへの動画アップロードの目的にのみ使用し、運営者が管理する環境に安全に保存します。

4. 第三者提供

取得した情報を第三者に販売・提供・共有することはありません。

5. Google API サービスの利用

本アプリによる Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。

6. アクセス権の取り消し

本アプリへのアクセス権は Google アカウントの権限設定 からいつでも取り消せます。
